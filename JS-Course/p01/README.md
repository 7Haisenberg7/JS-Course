 3.	Почему 0.1 + 0.2 !== 0.3 и как правильно хранить деньги?
 Компьютер считает в двоичной системе. Числа 0.1 и 0.2 превращаются в бесконечные дроби, которые JavaScript слегка округляет из-за лимита памяти. Погрешности складываются, выдавая на конце хвост: 0.30000000000000004.

5.Что вернут выражения и почему?
'' || 'нет' вернет 'нет'
 Почему: Логическое ИЛИ (||) ищет первое истинное значение. Пустая строка '' — это ложь (falsy), поэтому оператор идет дальше и возвращает 'нет'.
'' ?? 'нет' вернет '' (пустую строку)
 Почему: Оператор нулевого слияния (??) проверяет строго на null или undefined. Поскольку пустая строка '' — это существующее значение, оператор возвращает её сразу.
6.	Чем Number('12px') отличается от parseInt('12px')?
Number('12px') вернет NaN. Он пытается превратить строку в число целиком. Если в строке есть хоть один лишний нецифровой символ (кроме точек или минусов), он ломается.
parseInt('12px') вернет 12. Он сканирует строку слева направо, вытаскивает все цифры, пока не наткнется на буквы (px), отбрасывает их и возвращает число.

7.	Почему после const b = a изменение массива b видно в a?
Массивы в JavaScript являются объектами и копируются по ссылке, а не по значению.
Присваивание b = a не создает новый массив, а просто делает переменную b еще одним «пультом управления» от того же самого массива в памяти. Меняя данные через b, вы меняете тот же объект, на который смотрит a.

while — это цикл с предусловием. Он сначала проверяет условие, и если оно ложно, код внутри цикла может не выполниться ни разу.
do…while — это цикл с постусловием. Он сначала выполняет код, а только потом проверяет условие. Поэтому его тело гарантированно выполнится хотя бы 1 раз.

 10. Что показывают панели Scope, Watch и Call Stack в отладчике?
Scope (Область видимости): Показывает все переменные, доступные в текущей строке кода прямо сейчас (локальные, глобальные, переменные из замыканий).
 Watch (Наблюдение): Позволяет вручную вписать имя любой переменной или выражение, чтобы следить за изменением их значений в реальном времени в процессе пошаговой отладки.
 Call Stack (Стек вызовов): Показывает цепочку (историю) функций, которые были вызваны, чтобы дойти до текущей строчки кода (например: функция init вызвала getData, которая вызвала render).
